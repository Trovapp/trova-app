## 등록할 때 할 일

- [ ] EAS 설정(`eas.json`) 만들고 빌드·제출 연결
- [ ] App Store Connect 앱 정보: 배포 국가 대한민국만, 개인정보처리방침 주소, 지원 주소
- [ ] App Store "앱 개인정보 보호" 설문: 수집 항목은 방침 1항과 같게(식별자·사용자 콘텐츠·사용 데이터, 추적 없음)
- [ ] Play Console 데이터 보안 양식: 방침 1항·4항과 같게
- [ ] 심사용 테스트 계정 또는 로그인 안내 준비(소셜 로그인만 있음)
- [ ] 운영 구글 로그인: 구글 콘솔에 운영 redirect 주소 등록(2026-09-30 보류 상태)
